# QD4310 CAN 驱动

依据 `QD4310说明书.pdf`，QD4310 使用手册 V2.6，第 21-25 页。
接口采用现有 DM/RS05 的命名和实例风格，代码使用 C99。
两板 Keil/EIDE 已登记源码和头文件路径；所属任务尚未创建实例或调用驱动。

## 接口与职责

| 接口 | 用途 |
| --- | --- |
| `QD4310_MOTOR_CREATE(id)` | 固定 ID 初始化实例，其余状态清零，无硬件副作用 |
| `QD4310_Motor_SendCommand` | `QUERY` 查询反馈、`ENABLE` 使能、`DISABLE` 失能 |
| `QD4310_Motor_Control` | 选择五种模式之一并提交目标，可取得限幅后的目标值 |
| `QD4310_Motor_ControlTorque` | 将目标轴端力矩 N·m 按 0.27 N·m/A 换算为电流并发送 |
| `QD4310_Motor_OnRx` | 校验完整 HAL 帧与实际字节数，发布合法反馈及时间/序号 |

所属任务初始化 1 Mbit/s 总线、配置接收分发、安排使能顺序及周期，管理在线超时、重试和机械限位。
驱动每次只发一帧，不延时、不重试；反馈查询通过 NOP 完成，不改变控制目标。
使能成功须由新反馈确认。失能按电机协议释放输出，不代表制动或位置保持。
中断写反馈与任务读反馈需要由任务保证一致快照。

## 协议行为矩阵

| 操作/模式 | 合法目标及单位 | 帧及量化 | 越界/失败 | 副作用 |
| --- | --- | --- | --- | --- |
| 查询/使能/失能 | 三种基础命令 | `0x400+ID`，3 字节，命令+两个零字节 | 非法命令/ID 拒绝；HAL 失败报告发送失败 | 单次入队，不改本地反馈 |
| 电流 | ±10 A | `03`，小端有符号码，±32767 | 有限越界钳位；NaN/Inf 不发送 | 电机收到后切换电流模式 |
| 力矩 | ±2.7 N·m，按手册第 23 页的 0.27 N·m/A 换算 | 与电流模式相同 | 先在力矩单位中限幅，避免大数换算溢出；失败不改输出 | 单次电流模式入队，不计算位置闭环 |
| 速度 | ±104.719755 rad/s（±1000 rpm） | `04`，小端有符号码，±32767 | 同上 | 电机收到后切换速度模式 |
| 绝对角度 | 0-2π rad | `05`，小端无符号码，0-65535 | 钳位，无取模 | 单圈目标，电机沿较近方向运动 |
| 低速 | 与速度模式一致 | `06`，格式同速度 | 同电流模式 | 电机收到后切换低速模式 |
| 角度步进 | ±2π rad | `07`，小端有符号码，±32767 | 同电流模式 | 每帧都是新的增量，重试可能重复步进 |
| 反馈 | `0x500+ID`，8 字节经典标准数据帧 | Byte0 状态，Byte1 预留，Byte2-3 电流，Byte4-5 速度，Byte6-7 角度 | 坏帧不覆盖实例 | 仅合法帧更新反馈时间/序号 |

ID 为 0x00-0x0F；手册另说明同一总线最多连接 8 台 QD4310，不能使用重复 ID。
发送成功仅表示 HAL 接收入队；`applied` 是限幅后、整数编码前的目标，不代表实际输出。
电机额定电流 1 A、峰值 2 A，协议 ±10 A 是编码范围；任务须按负载设置运行限制。
电机 `limit.current` 等已有配置仍限制真实输出。本模块不提供校准或参数配置接口。
力矩接口的 ±2.7 N·m 仅对应协议 ±10 A，不是机械输出能力；手册额定/峰值扭矩分别为
0.2/0.3 N·m，任务仍须设置运行限制。`applied_torque_nm` 是限幅后、量化前的目标力矩，
不是实测力矩。换算宏也仅适用于 Q 轴电流，不适用于电源输入电流。

反馈的 `enabled` 只解释 Byte0 bit0，其他位和 Byte1 原样保存，不猜测故障定义。
`valid` 仅表示曾收到合法反馈；角度是单圈值，不累计多圈。
有符号反馈使用 `code/32767`，因此 -32768 得到略低于负满量程的测量值，保留该值供上层判断。
时间戳由调用者提供，时间和序号均允许无符号回绕。

## 调用示例

以下为接口片段，ID 和总线由具体任务按实际配置选择：

```c
static QD4310_Motor_Info_t motor = QD4310_MOTOR_CREATE(1U);

/* 总线启动并完成校准后，明确请求使能；是否已使能以新反馈确认。 */
QD4310_Motor_Status_e status = QD4310_Motor_SendCommand(
    &hfdcan1, &motor, QD4310_MOTOR_COMMAND_ENABLE);

/* 任务按安全门控决定何时发目标；只有 OK/CLAMPED 才更新 applied_current。 */
float applied_current = 0.0f;
status = QD4310_Motor_Control(&hfdcan1, &motor,
                            QD4310_MOTOR_MODE_CURRENT, 0.05f, &applied_current);

/* 目标 0.027 N·m 对应 0.1 A；位置闭环和运行力矩限制仍由所属任务完成。 */
float applied_torque_nm = 0.0f;
status = QD4310_Motor_ControlTorque(&hfdcan1, &motor, 0.027f, &applied_torque_nm);

/* 接收分发处：最后两个参数分别为实际字节数、接收时间，不能传缓冲容量。 */
status = QD4310_Motor_OnRx(&motor, &rx_header, rx_data, 8U, now_ms);
```

## 量化及验证边界

内部编码向零截断，端点精确给出完整码值。手册示例文字有舍入差异：
0.75 A 的 C 强转公式得到 2457，250 rpm 得到 8191；本实现遵循该截断规则。
角度按协议定义采用精确 2π；手册例程的 3.14 近似及角度 `int16_t` 强转不沿用。
设置零点、清错、重启、UART、外部闭环和任务接入均不在本轮范围。

主机测试直接编译真实驱动及工程 HAL 头，只在测试中捕获 HAL 发送并注入失败。
覆盖黄金字节、所有模式端点/限幅、量化步、NaN/Inf、非法参数、坏帧不更新、发送失败不更新、
有符号解码、单圈回绕、时间/序号回绕和全量程往返误差；力矩接口额外覆盖手册换算向量、
极大有限输入、协议满量程、非法输入和失败时输出保持不变。
测试及固件构建不能代替真实 CAN 通信、固件量化一致性、运行效果和机械安全验证。
